# Letecké nehody v datech

Repozitář obsahuje zpracování analýzy 5 268 záznamů leteckých nehod a dalších událostí z období 1908–2009.

## Obsah

- **Jupyter Notebook (`.ipynb`)** – příprava a kontrola dat, analytický kód, grafy a interpretace výsledků.
- **Power BI report (`.pbix`)** – interaktivní report se třemi listy: Přehled, Mapa a Detail.
- **PDF report (`.pdf`)** – statický náhled Power BI reportu.
- **Původní dataset (`.csv`)** – vstupní data pro analýzu.
- **Upravený dataset (`.csv`)** – připravená data doplněná o vypočtené ukazatele a kategorie pro Power BI.

Notebook lze otevřít v Jupyter Notebooku nebo Google Colabu, interaktivní report v Power BI Desktop.
